# 演策 YANCE · 决策预演工作台

[打开网站](https://kzczc.github.io/yance-decision-studio/)

演策将经营方案放进可观察的情景里：比较策略、理解人群反应，并形成下一步验证计划。

## 三类研究场景

| 模块 | 核心决策 | 主要指标 |
| --- | --- | --- |
| 企业增长 | 轻量自助引导与顾问陪伴激活 | 激活人数、激活率、7 日留存、每激活服务成本 |
| 商户经营 | 原价上市、全员尝新礼遇与会员专属礼遇 | 转化、成交、实收、贡献毛利、礼遇核销 |
| 公共服务 | 常规窗口、延时窗口与社区流动服务 | 完成办理、需求完成、重点人群覆盖、运营费用 |

每类场景都有独立参数、人群结构、策略对照与测算口径。切换模块不会覆盖其他研究设置。

## 产品功能

- 俯视像素街区与 32 位人物的行为可视化。
- 暂停、倍速、时间定位、全屏、人物画像及场景反馈。
- 可调策略、预算、周期、人群结构与评价目标。
- 方案比较、完整指标表、验证建议。
- 本地研究保存、再次载入、HTML 报告、CSV 表格与打印。
- 响应式布局、键盘操作与减少动态效果偏好。
- 中文标题 Noto Serif SC、正文 Noto Sans SC；西文衬线组合。字体已本地化及子集化。

## 本地运行

直接打开 `docs/index.html`，或启动静态服务：

```bash
python -m http.server 8000 --directory docs
```

## 部署

使用 GitHub Pages，发布 `main` 分支的 `/docs` 目录。无需构建或安装依赖。

## 数据与方法

这是完整的静态前端交互版本。当前行业场景使用透明、确定性的假设模型；没有连接后台多智能体推理或真实业务数据。人物用于解释行为路径，总体指标按研究设置的完整规模计算。实际实施前，需要使用获授权的业务数据校准，并通过真实试验验证。

工作空间与研究记录保存在当前浏览器的 localStorage，不上传服务器。报告包含来源与方法说明。

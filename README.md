# 演策 YANCE · 决策预演工作台

[打开网站](https://kzczc.github.io/yance-decision-studio/)

演策将经营方案放进可观察的情景里：比较策略、理解人群反应，并形成下一步验证计划。

## 三条产品线

| 产品 | 服务对象 | 当前可预演的具体问题 |
| --- | --- | --- |
| **GrowthLab · 企业增长** | 企业与业务团队 | 新用户引导、激活与留存 |
| **BizLab · 商户经营** | 店主与个体经营者 | 新品促销、客流与贡献毛利 |
| **PolicyLab · 政策决策** | 政府与公共机构 | 服务网点、时段与居民可达性 |

每类场景都有独立参数、人群结构、策略对照与测算口径。切换模块不会覆盖其他研究设置。

## 产品功能

- 俯视像素街区，可随业务规模自动调整或手动设置 8–128 位观察人物；人群权重与分群响应共同影响行为样本。
- 暂停、倍速、日期与时刻定位、1–2.5 倍地图缩放和平移、全屏人物详情。
- 白昼、傍晚、夜间自动光照，窗口与路灯随时段变化；不同经营方案有对应设施和路线。
- 标牌与对话通过独立高清文字层绘制，地图缩放不会放大文字像素。
- 可调策略、预算、周期、人群结构与评价目标；也可命名、复制并加入一套“我的策略”进行比较。
- 方案比较、完整指标表、验证建议。
- 本地研究保存、再次载入、HTML 报告、CSV 表格与打印。
- 响应式布局、键盘操作、字号与界面密度偏好；模块视图、播放进度和镜头位置自动保留。
- 减少动态模式、自动播放与播放速度偏好；暂停及隐藏场景停止帧循环。
- 中文标题 Noto Serif SC、正文 Noto Sans SC；西文衬线组合。字体已本地化及子集化。
- 页面使用暖纸白、灰绿、森林绿和砖橙，将周边工作台与像素街区的道路、绿地、屋顶统一起来；低对比路网纹理用于首屏背景。

## 本地运行

直接打开 `docs/index.html`，或启动静态服务：

```bash
python -m http.server 8000 --directory docs
```

## 部署

使用 GitHub Pages，发布 `main` 分支的 `/docs` 目录。无需构建或安装依赖。

## 数据与方法

这是完整的静态前端交互版本。当前行业场景使用透明、确定性的假设模型；没有连接后台多智能体推理或真实业务数据。人物用于解释行为路径，总体指标按研究设置的完整规模计算。自定义策略会在所选产品已有的行动模板上独立保存参数，因此每个结果仍能追溯到明确的计算口径。实际实施前，需要使用获授权的业务数据校准，并通过真实试验验证。

工作空间与研究记录保存在当前浏览器的 localStorage，不上传服务器。报告包含来源与方法说明。
